# واژه‌نامهٔ محصول

[English](../en/GLOSSARY.md) · [فهرست](INDEX.md)

اصطلاحات باید هماهنگ باشند، بدون اینکه شناسهٔ ماشینی تغییر کند. این واژه‌نامه راهنمای نگارشیِ مبتنی بر مشخصات است، نه استاندارد پروتکل تازه.

| اصطلاح | معادل فارسی | معنای مورد نظر در NextOps |
|---|---|---|
| Incident | رخداد | مشکل عملیاتی که بررسی می‌شود |
| Event | رویداد | اتفاق مشاهده‌شده در سامانهٔ منبع |
| Alert | هشدار | اعلان سامانهٔ پایش |
| Evidence | شواهد | مشاهده‌های دارای منبع برای پشتیبانی از تحلیل |
| Audit log | سابقهٔ ممیزی | ثبت امنیتی تصمیم، دسترسی و اثر عملیات |
| Connector | اتصال‌دهنده | رابط خانواده‌ای از تجهیزات یا سامانه‌های مجاز |
| Execution gateway | درگاه اجرا | مرز حفاظت‌شدهٔ هدایت و کنترل عملیات |
| Durable workflow | گردش‌کار ماندگار | پیشرفتی که پس از توقف فرایند حفظ می‌شود |
| Policy | سیاست اجرایی | قواعد معتبر و قطعی مجوز |
| Approval | تأیید عملیات | رضایت محدود به اقدام و وضعیت دقیق |
| Read-only | فقط‌خواندنی | بدون تغییر مورد نظر؛ همچنان محدود به مجوز و سقف اجرا |
| Root cause analysis | تحلیل علت ریشه‌ای | بررسی مبتنی بر شواهد، نه قطعیت پیش‌فرض |
| Hypothesis | فرضیه | توضیح احتمالی که هنوز تأیید نشده است |
| Topology | توپولوژی؛ ساختار ارتباطات | وابستگی میان تجهیزات و سرویس‌ها |
| Inference | اجرای مدل | تولید خروجی مدل از ورودی |
| Embedding | بردارسازی | تبدیل محتوا به بردار توسط مدل |
| Reranking | بازرتبه‌بندی | مرتب‌سازی دوبارهٔ نتایج بازیابی‌شده |
| Backpressure | کنترل پذیرش متناسب با ظرفیت | محدود کردن ورود کار هنگام اشباع منابع |
| Runbook | دستورالعمل عملیاتی | روش تشخیص یا اصلاحِ نام‌دار و بازبینی‌شده |
| Unknown outcome | نتیجهٔ نامشخص | احتمال اجرای راه دور وجود دارد و وضعیت باید بررسی شود |
| Rollback | بازگردانی | بازگشت مجاز به وضعیت پیشینِ سازگار |
| RPO | هدف نقطهٔ بازیابی | میزان هدف‌گذاری‌شدهٔ تحمل ازدست‌رفتن داده |
| RTO | هدف زمان بازیابی | زمان هدف بازگشت سرویس که در تمرین سنجیده می‌شود |

وضعیت `planned` یعنی برنامه‌ریزی‌شده؛ `simulated` یعنی شبیه‌سازی‌شده؛ `lab-verified` یعنی تأییدشده در آزمایشگاه؛ `production-validated` یعنی اعتبارسنجی‌شده در بهره‌برداری. همهٔ این‌ها نباید با یک برچسب مبهم «پشتیبانی می‌شود» جایگزین شوند.

کد، فیلد API، فرمان، IP، نام interface و شناسه به شکل اصلی باقی می‌مانند. خطای انگلیسی در کنار اصل پالایش‌شده‌اش به فارسی روان توضیح داده شود، نه اینکه محتوای فنی آن بازنویسی شود.

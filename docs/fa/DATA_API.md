# داده، گردش‌کار ماندگار، شواهد و API

[English](../en/DATA_API.md) · [فهرست](INDEX.md)

**وضعیت: قرارداد مفهومی؛ هنوز migration، schema یا endpoint پیاده‌سازی نشده است.** مبنا: بخش‌های ۱۱، ۱۶، ۱۷ و ۲۰ مشخصات اصلی. گروه‌بندی زیر نیازها را سازمان می‌دهد؛ ساختار دقیق داده و مسیرها هنگام پیاده‌سازی بازبینی می‌شوند.

## مدل ذخیره‌سازی

PostgreSQL مرجع معتبر وضعیت است و از پایگاه داده‌هایی که NextOps مدیریت می‌کند جدا می‌ماند. برای هر گروه، شناسهٔ ثابت، کلید خارجی، قید یکتا، index، دورهٔ نگهداری و قواعد دسترسی تعریف شوند.

| گروه | رکوردها و ارتباط‌ها |
|---|---|
| هویت و دامنه | سازمان، محیط، کاربر، نقش و مجوز محدود |
| موجودی | تجهیز، مقصد مجاز، قابلیت و نسخه، ارجاع اطلاعات ورود |
| اتصال | ثبت اتصال‌دهنده، نسخه و قابلیت ابزار |
| گردش‌کار | رخداد و رویداد، اجرا، گام، کار ماندگار، اجارهٔ کار و نقطهٔ ثبت پیشرفت |
| شواهد | منبع، تجهیز و دامنه، زمان مشاهده و جمع‌آوری، ارجاع محتوای پالایش‌شده و تازگی |
| اقدام | پیشنهاد، تأیید، تلاش اجرا و نتیجهٔ بررسی |
| دانش | سند، قطعهٔ متن، بردار، گفت‌وگو، حافظهٔ رخداد و گره و یال توپولوژی |
| حاکمیت | ممیزی و نسخهٔ مدل، پرامپت، سیاست و انتشار |

رابطهٔ مفهومی چنین است: سازمان محیط و کاربرِ دارای دامنه دارد؛ محیط شامل تجهیزات است؛ رخداد به تجهیزات درگیر و اجراهای گردش‌کار مرتبط می‌شود؛ هر اجرا گام و شاهد دارد؛ پیشنهاد به اقدام و مقصد دقیق و در صورت نیاز به تأیید وصل می‌شود؛ هر تلاش اجرا به پیشنهاد و شاهد بررسی نتیجه ارجاع می‌دهد. ممیزی نیز عامل، مقصد و عملیات مربوط را مشخص می‌کند. این توصیف schema اجرایی نیست.

زمان داخلی UTC باشد؛ منطقهٔ زمانی منبع، زمان جمع‌آوری و احتمال اختلاف ساعت حفظ شود. دادهٔ حساس به مجوز باید دامنه داشته باشد. نقش‌های پایگاه داده طوری محدود شوند که API یا برنامه‌ریز نتواند با نوشتن آزاد در پایگاه، تأیید اجرایی جعل کند.

## گردش‌کار ماندگار

```text
RECEIVED -> AUTHORIZED -> SCOPED -> PLANNED
  -> COLLECTING -> ANALYZING -> PROPOSAL_READY
  -> AWAITING_APPROVAL -> READY_TO_EXECUTE -> EXECUTING
  -> VERIFYING -> COMPLETED

DENIED / EXPIRED / CANCEL_REQUESTED / CANCELLED / FAILED
OUTCOME_UNKNOWN / MANUAL_RECONCILIATION_REQUIRED
```

بررسی فقط‌خواندنی از تأیید تغییر عبور نمی‌کند، اما همچنان مجوز و ممیزی لازم دارد. پیشرفت پیش و پس از اثر خارجی ثبت شود. در صورت نیاز ایجاد کار و outbox تراکنشی، اجارهٔ worker، heartbeat و تشخیص تکرار به‌کار رود. اجرای دقیقاً یک‌باره میان تجهیز و PostgreSQL ادعا نشود. پیش از تکرار تغییرِ احتمالاً اجراشده، وضعیت مقصد بررسی شود. لغو محلی تضمین لغو راه دور نیست.

زمان کل، تعداد فراخوانی مدل و ابزار، توکن، بایت، پراکندگی کار و تکرار محدود شوند. نمونهٔ شش فراخوانی مدل و بیست فراخوانی ابزار در مشخصات، نقطهٔ شروع آزمایش است، نه مقدار بهینهٔ اندازه‌گیری‌شده.

## شواهد، بازیابی و توپولوژی

منشأ، نسخهٔ منبع، زمان منبع و جمع‌آوری، هش محتوا، دامنهٔ مجوز و نشانهٔ پالایش یا ناقص بودن ثبت شوند. دسترسی پیش از بازیابی و هنگام ارائهٔ شاهد کنترل شود. رخداد قدیمی اثبات وضعیت فعلی نیست. تا حد امکان تاریخچهٔ خام پایش در سامانهٔ اصلی باقی بماند.

توپولوژی ابتدا با یال‌های رابطه‌ای شامل نوع رابطه، منبع، تازگی و وضعیت مشاهده‌شده یا استنباطی ساخته شود. فقط سند تغییرکرده دوباره نمایه‌سازی شود. نسخهٔ قطعه و مدل بردارسازی و ابعاد ثبت شوند. تغییر مدل بردارسازی نیازمند سازگاری نمایه است. cache نیز باید دامنه و تازگی را رعایت کند.

خروجی تحلیل علت ریشه‌ای باید نشانه‌ها، شواهد، علت‌های احتمالی، شواهد موافق و مخالف، اطمینان همراه دلیل، مجهولات، گام تشخیصی بعدی و اقدام پیشنهادی با ریسک و تأیید و بررسی نتیجه را جدا کند. عنوان «علت تأییدشده» فقط با شاهد کافی به‌کار رود. احتمال عددیِ بدون اعتبارسنجی تولید نشود.

## رفتار پیشنهادی API

فضای `/api/v1` برای گفت‌وگو، اجرا، عامل، اتصال‌دهنده، تجهیز، رخداد، شاهد، تأیید، ممیزی، کاربر، نقش، تنظیمات و مدل در نظر گرفته می‌شود. اگر کد قدیمی بعداً وارد شد، حفظ مسیرهای قبلی تصمیم سازگاری صریح می‌خواهد. endpointهای زنده‌بودن و آمادگی نباید جزئیات حساس عمومی بدهند.

درخواست طولانی یک اجرای ماندگار می‌سازد و شناسهٔ آن را برمی‌گرداند. جریان پیشرفتِ احرازهویت‌شده امکان اتصال دوباره دارد. لغو، درخواست توقف است نه اثبات توقف کار راه دور. صفحه‌بندی، سقف payload، ثبت تکرارپذیر فرمان و خطای ساخت‌یافته تعریف شوند. timeout مرورگر کار را حذف نمی‌کند.

ورودی هشدار باید schema معتبر، فرستندهٔ دارای دامنه، کنترل بازپخش و تکرار و سقف نرخ داشته باشد. دادهٔ خراب به بازبینی دستی برود. ورودی ناشناس حق اجرای عملیات دلخواه ندارد و مرورگر نیز به مدل یا اتصال‌دهنده مسیر مستقیم نخواهد داشت.

# فهرست مستندات

[English](../en/INDEX.md) · [صفحهٔ اصلی](../../README_FA.md) · [شروع کار](START_HERE.md)

**به‌روزرسانی: ۴ مهر ۱۴۰۵. وضعیت: مسیر دوزبانهٔ مرحلهٔ دو و مرز قطعی صحت پاسخ روی چهار مهمان مستقر و واجد شرایط شده‌اند.** چهار مقصد ثابت Linux، تاریخچه و رویداد محدود Zabbix، پاسخ ماندگار مدل محلی CPU و پیوند شاهد و ممیزی زنده‌اند. CI منبع، ارزیابی دوزبانهٔ مدل، API زنده، راه‌اندازی مجدد، بازگشت انتشار، قطع WAN، مرورگر احرازهویت‌شده، بازیابی وابستگی و reboot ترتیبی موفق‌اند. مالک کارهای بازیابی را فعلاً کنار گذاشته و مسیر SMTP وجود ندارد؛ بنابراین پذیرش تولید و تحویل اعلان بازند. [وضعیت ماشین‌خوان انتشار](../status/current-release.yaml) را ببینید.

> **چیدمان فعلیِ سرور جدید:** سه ماشین NextOps به‌علاوهٔ `zabbix-server` با ۴ vCPU، حافظهٔ ۱۶ GiB و دیسک ۲۰۰ GiB؛ در مجموع **۴ ماشین، ۴۰ vCPU، حافظهٔ ۱۸۴ GiB و دیسک ۹۸۰ GiB**. آزمایشگاه کوچک قبلی نیز به آن اضافه نشود. [راهنمای شروع](START_HERE.md) ترتیب و گام‌های 1A تا 1E را دارد؛ [راهنمای Zabbix](ZABBIX_SERVER.md) ماشین پایش، LVM و اتصال فقط‌خواندنی را مشخص می‌کند.

> **شرط الزامی:** پاسخ CPU محلی، ورود تازه و شروع سرد بدون اینترنت کار کنند. پیش از انتخاب وابستگی، [الزام آفلاین](OFFLINE_RUNTIME.md) خوانده شود. GitHub سرویس زمان اجرا نیست.

> **مسیر تحویل‌شده:** مرحلهٔ یک پاسخ محلی و مستند Zabbix را با WAN مسدود برقرار کرد؛ مرحلهٔ دو شواهد مستقیم و محدود Linux را برای چهار مقصد مصوب افزود. سرور مستقل پیش از خواندن زندهٔ 1C آماده شود یا از Zabbix موجودِ مناسب و مجاز استفاده شود.

## منابع و پیگیری

[منابع](../requirements/SOURCES.md)، [پرامپت فعال](../requirements/NEXTOPS_MASTER_PROMPT.md)، [منبع محفوظ نسخهٔ ۲](../requirements/archive/NEXTOPS_MASTER_PROMPT_v2.0.md)، [ردیابی](../requirements/TRACEABILITY.md)، [تصمیم‌ها](../adr/README.md)، [وضعیت پروژه](../PROJECT_STATE.md) و [کار بعدی](../NEXT_TASK.md) خوانده شوند. [بازبینی تصویری](../VISUAL_REVIEW.md) آزمون اجرایی آفلاین نیست.

هر راهنمای فارسی همتای هم‌نام انگلیسی دارد و هر دو با هم به‌روز می‌شوند. شناسهٔ اجرایی، فیلد پروتکل و پرامپت ترجمه نشوند. رمز و شناسهٔ واقعی زیرساخت در مخزن عمومی نباشند. مستندات و بودجهٔ محاسبه‌شده، شاهد نصب سرویس یا قبولی آزمون نیستند.

# فهرست مستندات

[English](../en/INDEX.md) · [صفحهٔ اصلی](../../README_FA.md) · [شروع کار](START_HERE.md)

**به‌روزرسانی: ۲۰ سپتامبر ۲۰۲۶. وضعیت: مستندات و طرح پیشنهادی، نه اثبات کارکرد محصول.** پرامپت فعال انگلیسی است و مشخصات اولیهٔ فارسی در بایگانی محفوظ نسخهٔ ۲ قرار دارد.

> **چیدمان فعلیِ سرور جدید:** سه ماشین NextOps به‌علاوهٔ `zabbix-server` با ۴ vCPU، حافظهٔ ۱۶ GiB و دیسک ۲۰۰ GiB؛ در مجموع **۴ ماشین، ۴۰ vCPU، حافظهٔ ۱۸۴ GiB و دیسک ۹۸۰ GiB**. آزمایشگاه کوچک قبلی نیز به آن اضافه نشود. [راهنمای شروع](START_HERE.md) ترتیب و گام‌های 1A تا 1E را دارد؛ [راهنمای Zabbix](ZABBIX_SERVER.md) ماشین پایش، LVM و اتصال فقط‌خواندنی را مشخص می‌کند.

> **شرط الزامی:** پاسخ CPU محلی، ورود تازه و شروع سرد بدون اینترنت کار کنند. پیش از انتخاب وابستگی، [الزام آفلاین](OFFLINE_RUNTIME.md) خوانده شود. GitHub سرویس زمان اجرا نیست.

> **اولین خروجی:** پاسخ واقعی، محلی و مستند دربارهٔ وضعیت مجاز Zabbix با اینترنت قطع. بررسی مستقیم Linux در مرحلهٔ دو است. سرور مستقل پیش از خواندن زندهٔ 1C آماده شود یا از Zabbix موجودِ مناسب و مجاز استفاده شود.

## منابع و پیگیری

[منابع](../requirements/SOURCES.md)، [پرامپت فعال](../requirements/NEXTOPS_MASTER_PROMPT.md)، [منبع محفوظ نسخهٔ ۲](../requirements/archive/NEXTOPS_MASTER_PROMPT_v2.0.md)، [ردیابی](../requirements/TRACEABILITY.md)، [تصمیم‌ها](../adr/README.md)، [وضعیت پروژه](../PROJECT_STATE.md) و [کار بعدی](../NEXT_TASK.md) خوانده شوند. [رکورد تخصیص Zabbix](../requirements/ZABBIX_SERVER_PLAN.json) و [اصلاحیه](../requirements/DEPLOYMENT_UPDATE.md) پیشنهاد منابع را از مشاهدهٔ سخت‌افزار جدا می‌کنند. [بازبینی تصویری](../VISUAL_REVIEW.md) آزمون اجرایی آفلاین نیست.

هر راهنمای فارسی همتای هم‌نام انگلیسی دارد و هر دو با هم به‌روز می‌شوند. شناسهٔ اجرایی، فیلد پروتکل و پرامپت ترجمه نشوند. رمز و شناسهٔ واقعی زیرساخت در مخزن عمومی نباشند. مستندات و بودجهٔ محاسبه‌شده، شاهد نصب سرویس یا قبولی آزمون نیستند.

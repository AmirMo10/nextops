# ADR 0006 — Evidence-qualified RCA and bilingual UI

Status: accepted on 2026-09-21. Source: master sections 3, 14, 16–17, 21.

## English

RCA separates observations, hypotheses, supporting/contradictory evidence and verified causes. Use justified confidence labels unless numeric probabilities are calibrated. Historical memory is not proof of current state. Scope and freshness are enforced before retrieval and evidence display.

Provide native Persian RTL and English LTR with isolated technical identifiers, local assets and reusable accessible components. Show concise decision summaries, tool activity and sanitized evidence—not unrestricted internal reasoning. Original logs/commands remain intact except explicit secret redaction. Consequence: more careful provenance and language tests, with no fabricated certainty or secret-bearing display.

## فارسی

وضعیت: پذیرفته‌شده در ۲۱ سپتامبر ۲۰۲۶. تحلیل علت، مشاهده، فرضیه، شاهد موافق و مخالف و علت تأییدشده را جدا می‌کند. تا پیش از اعتبارسنجی احتمال عددی، برچسب اطمینان همراه دلیل به‌کار رود. حافظهٔ تاریخی اثبات وضعیت فعلی نیست. دامنه و تازگی پیش از بازیابی و نمایش کنترل شوند.

فارسی طبیعیِ راست‌به‌چپ و انگلیسی چپ‌به‌راست با جداسازی شناسهٔ فنی، دارایی محلی و اجزای مشترک دسترس‌پذیر ارائه شوند. خلاصهٔ تصمیم، فعالیت ابزار و شواهد پالایش‌شده نمایش داده شوند، نه استدلال داخلی نامحدود. لاگ و فرمان اصلی جز پالایش صریح رمز دست‌نخورده می‌مانند. پیامد: آزمون دقیق‌تر منبع و زبان، بدون قطعیت ساختگی یا نمایش اطلاعات محرمانه.
